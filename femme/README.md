# neV.BOOSTER — Parcours féminin

Dossier `femme/` du site. Les joueuses (sexe « féminin » choisi à l'inscription) y sont envoyées automatiquement :
1re connexion → `femme/intro.html` (animation), ensuite → `femme/index.html`.

Guide : **Yuki** (images fournies par toi, dans `img/`). À chaque connexion (nouvelle session du navigateur),
elle affiche : « Quel est ton type de mec ??! » (fonction `yukiHello` dans `script.js`, texte `YUKI_LINE`).

Pages : intro, index, guide, programmes, gacha (Gacha Box 4 cartes dont 1 Combo), progression, niveau, communauté.
Progression enregistrée dans le navigateur (clé `nvbf.v1`). Exercices : tableau `CATS` dans `script.js`.
Les polices viennent de `../fonts/fonts.css` (aucun service externe : compatible avec la sécurité du site).

Attention droits d'auteur : Yuki Tsukumo est un personnage de l'anime « Jujutsu Kaisen ». Pour un site public ou
commercial, il faut l'autorisation des ayants droit, ou remplacer `img/yuki-*.webp` par un personnage original.
